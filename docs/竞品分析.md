# 枫叶笔记 — 竞品分析报告

> 调研时间：2026-05-20
> 调研范围：语雀、飞书文档、印象笔记、有道云笔记、Notion、Obsidian、FlowUs、Wolai、幕布、Flomo、思源笔记

## 一、国内主流笔记平台概览

### 1.1 笔记型工具

| 平台 | 所属 | 免费空间 | 核心优势 | 主要短板 |
|------|------|---------|---------|---------|
| **印象笔记** | 独立 | 60MB/月 | OCR、多格式附件、跨平台、微信收藏 | 编辑器臃肿、广告多、Markdown 弱 |
| **有道云笔记** | 网易 | 3GB | 微信文章保存、语音转文字、手写笔记 | 产品迭代停滞、功能平庸 |
| **语雀** | 阿里 | 基础免费 | 知识库分级、代码块/公式/流程图、界面现代 | 泛信息剪藏弱、单附件 30MB |

### 1.2 双向链接 / 知识图谱工具

| 平台 | 存储 | 核心优势 | 适用场景 |
|------|------|---------|---------|
| **Obsidian** | 本地 MD | 双向链接、插件生态、知识图谱、本地优先 | 学术研究、深度思考 |
| **Logseq** | 本地 MD/Org | 开源、大纲+块引用、双向链接 | 结构化笔记 |
| **幕布** | 云端 | 大纲一键转思维导图、模板库 | 思维整理 |

### 1.3 协作型平台

| 平台 | 所属 | 核心优势 | 适用场景 |
|------|------|---------|---------|
| **飞书文档** | 字节跳动 | 深度整合飞书生态、多人实时协作、AI 总结 | 企业团队 |
| **Notion** | 海外 | All-in-one、数据库视图、模块化搭建 | 个人/团队通用 |
| **FlowUs** | 国产 | Notion 替代、微信内容引用、中文客服 | 团队知识沉淀 |
| **Wolai** | 国产 | 块编辑器、数据库/看板视图、模板丰富 | 个人/小团队 |
| **石墨文档** | 国产 | 多人实时协作、划词评论、版本历史 | 中小团队 |

### 1.4 本地 / 私有化部署

| 平台 | 技术栈 | 特点 |
|------|-------|------|
| **思源笔记** | 本地优先 | 双向链接、开源社区、AES 加密、68 元/端买断 |
| **MrDoc** | Python+Django | 开源、MD+所见即所得、Docker 部署 |

## 二、枫叶笔记 vs 竞品 — 功能差距矩阵

### 2.1 致命短板（缺少则无法在同类产品中立足）

| # | 功能 | 竞品现状 | 枫叶笔记 | 状态 |
|---|------|---------|---------|------|
| 1 | **代码块语法高亮** | 语雀/Notion/Obsidian 均支持 | 已实现（highlight.js + atom-one-dark） | ✅ |
| 2 | **所见即所得编辑器** | 飞书/语雀/Notion 均有 | 原始 `<textarea>` + 手写 toolbar | ❌ |
| 3 | **全文搜索** | 竞品用 ES/Lucene | SQL `LIKE`，无分词、无拼音 | ❌ |

### 2.2 核心差距（2025 年用户期望的基本能力）

| # | 功能 | 重要性 | 说明 |
|---|------|--------|------|
| 4 | **AI 智能助手** | ⭐⭐⭐⭐⭐ | 语雀 AI 写作、飞书 AI 总结、Notion AI Q&A。枫叶笔记零 AI 能力 |
| 5 | **笔记分享** | ⭐⭐⭐⭐ | 生成只读分享链接，几乎所有平台标配 |
| 6 | **笔记模板** | ⭐⭐⭐⭐ | 会议纪要、周报、读书笔记等预制模板 |
| 7 | **更多导出格式** | ⭐⭐⭐⭐ | 仅支持 `.md`，竞品支持 PDF、Word、HTML、ePub |
| 8 | **笔记内嵌图片/附件** | ⭐⭐⭐⭐ | 笔记正文可粘贴图片、上传文件，目前仅头像上传 |
| 9 | **暗色模式** | ⭐⭐⭐⭐ | 飞书/语雀/Notion/Obsidian 全部支持 |

### 2.3 锦上添花（差异化竞争力）

| # | 功能 | 说明 |
|---|------|------|
| 10 | **双向链接 + 知识图谱** | Obsidian 风格 `[[互相引用]]`，可视化图谱 |
| 11 | **笔记版本历史** | 查看/恢复历史版本 |
| 12 | **网页剪藏** | 浏览器插件一键保存网页 |
| 13 | **OCR 文字识别** | 图片中的文字可搜索 |
| 14 | **语音笔记** | 录音 + 语音转文字 |
| 15 | **多视图模式** | 看板/日历/画廊/表格视图，大纲转思维导图 |
| 16 | **移动端 / PWA** | iOS/Android/鸿蒙 App |
| 17 | **离线支持** | PWA + Service Worker |

## 三、2025 年行业趋势

1. **AI 深度融合**：智能大纲生成、语音转写摘要、AI 自动关联推荐成为标配
2. **隐私安全升级**：本地存储 + 端到端加密工具（思源、Obsidian）用户增长
3. **多端协同**：主流工具已覆盖 Windows/Mac/iOS/Android/Web，部分适配鸿蒙
4. **模块化与定制化**：Notion 式「块编辑」理念被更多国产工具采纳

## 四、建议优先级路线图

```
Phase 1（基础体验补全）
├── ✅ 代码语法高亮（highlight.js + marked-highlight）
├── ✅ 所见即所得编辑器（Milkdown / Tiptap / ByteMD）
├── ✅ 暗色模式
├── ✅ 笔记内嵌图片
└── ✅ 更多导出格式（PDF）

Phase 2（AI 集成 — CLAUDE.md 重点目标）
├── ⬜ Spring AI + RAG（笔记向量化 + 语义搜索）
├── ⬜ AI 写作助手（续写/总结/翻译）
└── ⬜ AI 自动打标签 + 分类推荐

Phase 3（编辑器升级）
├── ⬜ 替换为成熟编辑器（Milkdown / Tiptap / ByteMD）
└── ⬜ 快捷键系统、自动补全

Phase 4（生态完善）
├── ⬜ 笔记只读分享链接
├── ⬜ 版本历史
└── ⬜ PWA 离线支持
```

## 五、AI 集成方向（预留）

CLAUDE.md 明确提到 RAG 和 Spring AI：

1. **语义搜索**：Spring AI + PGVector / Redis，自然语言搜笔记（「找关于 Spring Security 配置的笔记」）
2. **AI 写作**：选中文字 →「润色/扩写/总结/翻译」
3. **智能标签**：根据笔记内容自动推荐标签
4. **知识问答**：基于用户笔记库做 RAG 问答
